کوهستان برفی 1942 - پروژه آزمایشی سبک

محتوا:
- یک واگن/خودروی ریلی کوچک قابل کنترل در یک روستای کوچک
- یک جاده آسفالت و یک جاده خاکی
- کوه‌های برفی ساده
- خانه‌ها و درختان روستا
- چند هواپیمای شوتر دشمن در بالای سر واگن که آن را دنبال می‌کنند
- شلیک آزمایشی هواپیماها به سمت واگن
- بدون APK؛ این ZIP فقط سورس پروژه Godot است.
- همه عناصر رویه‌ای و بسیار سبک ساخته شده‌اند تا حجم پروژه کمتر از 20MB بماند.

کنترل:
W/S حرکت
A/D گردش


استاندارد Git پروژه:
- Branch اصلی: main
- Remote پیشنهادی: origin
- این پروژه از ابتدا برای قرار گرفتن در Repository با Branch اصلی main آماده شده است.

کنترل خودرو/واگن:
- ۵ دنده: ۱، ۲، ۳، ۴، ۵
- دنده با کلیدهای 1 تا 5 انتخاب می‌شود.
- W پدال گاز است و مقدار فشار آن با شدت ورودی تعیین می‌شود.
- نگه داشتن W به‌تنهایی باعث شتاب‌گیری خودکار و بی‌نهایت نمی‌شود.
- سرعت نهایی هر دنده محدود است و به میزان گاز و دنده وابسته است.
- با برداشتن گاز، نیروی موتور قطع می‌شود و خودرو بر اساس اصطکاک و مقاومت کاهش سرعت می‌دهد.
- S ترمز/دنده‌عقب آزمایشی است.
